### **Project Overview**
This repository contains all reports, documentation, work logs, and artifacts for the CSIS 4440 Mobile Cybersecurity Group Project. The project focuses on Android mobile forensics using open-source tools to extract, analyze, and interpret artifacts from selected Android applications.

### **Integrated Component**
Both students will contribute to a **Combined Forensic Dashboard** (CSV/Excel or script-generated). This dashboard will summarize:

- Extracted artifact paths & timestamps  
- Database and cache locations  
- App behavior indicators  
- Cross-app correlation (evidence timelines)

This integration will demonstrate how forensic evidence from multiple tools and apps can be **combined into one clear, investigative view**.
